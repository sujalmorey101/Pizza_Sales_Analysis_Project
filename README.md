**Author: Sujal More**
Data Analytics Portfolio Project

---

## 👨🏻‍💻 Project Overview

This project demonstrates a complete, industry-standard data analytics 
workflow built around real-world pizza sales data. It showcases 
proficiency across the full analytics stack — SQL, Excel, Power BI 
and Tableau — taking raw transactional data and transforming it into 
meaningful business insights through structured analysis and 
compelling visualizations.

---

## 📂 Dataset
**Pizza Sales Data 2015**
Source: Kaggle.com
Transactional sales data covering orders, quantities, categories, 
sizes and revenue across an entire calendar year.

---

## ❓ Problem Statement

The objective was to thoroughly examine key business metrics within 
the pizza sales dataset to extract actionable insights into 
operational performance. This required building comprehensive 
visualizations to identify trends, evaluate category performance 
and support data-driven decision making.

---

## 📊 Key Metrics Analyzed

| Metric | Description |
|---|---|
| Total Revenue | Sum of total price across all orders |
| Average Order Value | Total revenue divided by total orders |
| Total Pizzas Sold | Sum of all pizza quantities sold |
| Total Orders | Count of all unique orders placed |
| Avg Pizzas Per Order | Total pizzas sold divided by total orders |
| Sales by Category & Size | Demand distribution across types and sizes |

---

## 📉 Visualizations Built

**Daily Trend for Total Orders**
Bar chart displaying daily order volumes over time — used to 
identify patterns and fluctuations in day-to-day demand.

**Monthly / Weekly / Hourly Trends**
Line charts illustrating order activity across different time 
periods — used to pinpoint peak hours, busy days and seasonal 
patterns.

**Sales by Pizza Category**
Pie chart showing revenue distribution across pizza categories — 
highlights which categories drive the most sales and their 
contribution to overall revenue.

**Best & Worst Sellers**
Ranked visualizations identifying top performing and 
underperforming pizzas by revenue, quantity and order volume — 
critical for menu optimization decisions.

---

## 🗂️ Project Phases

### Phase 1 — Data Acquisition & SQL
- Acquired and managed data within MS SQL Server
- Wrote SQL queries to extract key metrics — total revenue, 
  order counts, category performance and sales trends
- Validated data integrity before analysis

### Phase 2 — Excel Dashboard
- Built an interactive Excel dashboard using pivot tables
- Created dynamic charts for trend analysis and KPI tracking
- Designed for non-technical stakeholders to explore data easily

### Phase 3 — Power BI Dashboard
- Developed a dynamic, interactive Power BI dashboard
- Integrated multiple data dimensions into unified visual reports
- Focused on clear, executive-ready visualizations with slicers 
  and drill-down capabilities

### Phase 4 — Tableau Visualization
- Recreated the dashboard in Tableau with custom chart types
- Developed complex calculated fields and trend analyses
- Leveraged Tableau's storytelling capabilities for deeper insights

---

## 💡 Key Insights Uncovered

- Identified peak ordering days and hours for staffing optimization
- Determined top selling and underperforming pizza categories
- Revealed revenue contribution by size and category
- Highlighted seasonal demand patterns for inventory planning
